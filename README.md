# Marib To‑Do App

This repository contains a full-featured To‑Do app (frontend + optional backend skeleton).

Features included:
- React + Vite (TypeScript-ready)
- LocalStorage persistence
- Inline editing
- Drag & drop ordering (using @hello-pangea/dnd)
- Due dates and basic browser notifications
- Export / Import JSON
- Optional simple Express backend skeleton (server/)

Quick start (install Node.js 18+):

1. Install dependencies:
   npm install
2. Run the frontend dev server:
   npm run dev
3. (Optional) Run the backend server:
   npm run server

Open http://localhost:5173
